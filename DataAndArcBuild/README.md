### Задача кредитного скоринга
* Определить, уйдёт ли клиент в дефолт по кредитному продукту или нет

Процентная ставка состоит из:
* ставка ЦБ
* маржа банка
* risc cost

### Скоринг на данных кредитных историй
1) Получаем app_id
2) отправляем запросы в:
   * ОКБ -> Объединённое Кредитное Бюро
   * НБКИ -> Национальное Бюро Кредитных Историй
   * Эквифакс
3) берём кредитную историю клиента
