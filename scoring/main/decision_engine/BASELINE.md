# Начальная экономическая политика MVP на 24.10.2026

Версия `AURELIUS_MVP_20261024_V1`, продукты R01/R02/R03, действует с 24.10.2026
по 17.12.2026 включительно. Все продукты используют одинаковую базовую политику:
нет данных для достоверной отдельной калибровки каждого продукта.

| Параметр | Значение | Основание |
|---|---:|---|
| KEY_RATE | 14% годовых | Официальное решение ЦБ; действует с 27.07.2026, подтверждено 23.10.2026 |
| funding_spread_pct | 1.5 п.п. | Допущение MVP о дополнительной стоимости фондирования/ликвидности |
| operating_cost_pct | 2 п.п. | Допущение MVP о ежегодных операционных расходах относительно суммы под риском |
| required_margin_pct | 3 п.п. | Целевая остаточная доходность MVP; отдельно капитал не калиброван |
| lgd_pct | 45% | Консервативное допущение: внешний ориентир 40% + 5 п.п. буфера неопределённости |

Решения ЦБ:
- https://www.cbr.ru/press/pr/?file=24072026_133000key.htm
- https://www.cbr.ru/press/pr/?file=23102026_133000key.htm

Внешний ориентир LGD 40% для senior unsecured non-financial corporates:
https://www.bankofengland.co.uk/prudential-regulation/publication/2022/november/implementation-of-the-basel-3-1-standards/credit-risk-internal-rating-based
пункты 4.236–4.237. Это внешний ориентир foundation IRB; не оценка потерь
российского МСП, не норма для всех ИП и не внутренняя политика Альфа-Банка.
Буфер 5 п.п. — отдельное допущение проекта, не требование указанного источника.

Расходы, спред и маржа не подтверждены публичной продуктовой ставкой или
отчётностью банка. Их нельзя выдавать за измеренные показатели. Они выбраны
как прозрачная стартовая конфигурация с запасом на издержки; подтвердить их
реалистичность для конкретного кредитора можно только по его данным.

Пример: индивидуальная ставка 23.5% → F=15.5%, запас=3 п.п., PD_limit=6.6667%.
При ставке 28% → запас=7.5 п.п., PD_limit=16.6667%. Сам PD_limit не хранится
одним числом в справочнике: он считается для индивидуальной ставки заявки.

Дата окончания — срок пересмотра допущений перед запланированным заседанием ЦБ
18.12.2026, не прогноз изменения ставки. Дальше нужна новая версия политики.
Новая ключевая ставка загружается новым наблюдением без перезаписи истории.

## Заполнение

Из корня проекта с настроенным DATABASE_URL:

```powershell
python -m main.seed_policy          # проверить все INSERT, затем ROLLBACK
python -m main.seed_policy --apply  # атомарно сохранить
```

Повтор идентичного seed не создаёт дубликаты. Несовпадение существующей версии,
пересечение периодов политик или конфликт макронаблюдения прекращают операцию.
Схема БД, компании, заявки, учётные записи и результаты скоринга не изменяются.
Источники/допущения хранятся в `baseline_20261024.json`, входят в аудит расчёта
для этой версии политики; фактические числовые параметры читаются из БД.

Заполнение этих таблиц решает получение экономических параметров, но не
восстанавливает из БД синтетический признак модели `macro_stress`.
