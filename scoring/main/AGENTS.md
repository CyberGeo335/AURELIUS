# Дополнительное правило владельца проекта

После любого изменения рабочей PostgreSQL-базы (включая данные справочников)
сделать новый полный дамп структуры и данных в следующую `bd/v_N (actual)`.
Также сохранить schema-only SQL и проверить восстановление/состав дампа.
Только после проверки убрать `(actual)` у предыдущей папки; старые снимки
не удалять и не перезаписывать. Подробнее: `../bd/README_versions.md`.
Это не относится к одноразовым тестовым базам.
