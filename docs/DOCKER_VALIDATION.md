## Оставшиеся ограничения

Три ошибки — существующие тесты personalCab/prom_v2/tests/test_assessment.py.
Они обращаются к старому AssessmentService и отсутствующему в ветке
scoring/models/registry.json (также нужны соответствующие старые артефакты).
Сервис возвращает MODEL_REGISTRY_UNAVAILABLE, тесты ожидают успешную оценку.
Та же ошибка воспроизведена в исходном окружении до Docker; тесты не отключались,
фиктивный реестр/модели не создавались. Для полного зелёного набора требуется
отдельное решение владельца об этих отсутствующих артефактах/старом контракте.
Текущий cabinet_server использует scoring/main и от этого реестра не зависит.

55 пропусков общего прогона связаны с отсутствием выделенных внешних интеграций
в этом прогоне; они не объявляются успешно выполненными. Актуальные 20 тестов
кабинета дополнительно выполнены с явным AURELIUS_TEST_DATABASE_URL.

На настоящих Windows/PowerShell и NVIDIA запуск не проверен. start.ps1 сохранён
в UTF-8 с BOM для Windows PowerShell. Полная холодная загрузка 14 ГБ gpt-oss:20b
во встроенный Ollama отдельно не выполнялась: проверен установленный внешний
экземпляр, а ветви fallback/pull/ошибок покрыты тестами. Официальный multiarch
образ Ollama проверен через registry и закреплён digest в Compose.

HTTPS-прокси не настраивался. Текущую HTTP Origin-проверку кабинета не меняли.
До разрешения владельца push не выполняется.
