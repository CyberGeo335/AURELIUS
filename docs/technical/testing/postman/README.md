# API regression для текущего кабинета

`cabinet-regression.postman_collection.json` предназначена только для синтетической seeded тестовой БД `aurelius_test*` (v4). Она создаёт и подаёт одну заявку R01. Используйте отдельный HTTP-сервер, подключённый к этой БД.

Исходная старая коллекция не найдена в рабочей копии; этот файл — воспроизводимая замена. ОКВЭД отправляется только кодом. Отсутствующие реквизиты дополняются типизированными синтетическими ответами только в заявке. Для клиента проверяется отсутствие неопубликованного предложения; сотруднику предложение разрешено, если его ID указан в результате текущего расчёта. Фиксированного ожидания «предложения нет на старом дампе» нет.

Создайте вне Git приватный Newman environment с ключами `base_url`, `client_login`, `client_password`, `bank_login`, `bank_password`. Клиент и сотрудник должны быть активными тестовыми учётными записями из этой БД. `base_url` задаётся без завершающего `/`; тот же адрес отправляется в Origin.

```sh
newman run docs/technical/testing/postman/cabinet-regression.postman_collection.json -e /private/tmp/cabinet-regression.env.json --bail
```

В Docker на macOS используйте `http://host.docker.internal:PORT` в приватном environment. Пароли не передавайте аргументами `--env-var`, не сохраняйте в репозиторий и не включайте в экспорт HTTP-трафика.

Проверка 2026-10-26: 11 запросов, 17 assertions, 0 failures. Включены чужой Origin (403), вход, создание, сохранение кода ОКВЭД, подача и повтор с тем же request_id, серверная фильтрация причин для клиента и доступ сотрудника к текущему расчёту.
