# Каталог требований

Версия и источники — [PROGRESS](PROGRESS.md). C — требования кейса; T — продуктовые решения команды; D — развитие. P0/P1 — **редакционная приоритизация для проверки и пилота**, а не историческая оценка команды. P0 блокирует целостность процесса; P1 расширяет его. Статус реализации означает наличие кода, результат отдельного запуска нужно смотреть в протоколах.
