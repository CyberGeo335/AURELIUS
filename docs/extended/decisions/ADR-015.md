# ADR-015: Три продукта в заявке, 16 направлений в подборе

Статус: действует в срезе `68b7b57c0e501e4575bc2a10eee20e6e42f529d4`. Дата принятия и автор ADR отдельно не установлены; развёрнуто 26.10.2026 из решения **Р15**. Это дата документирования, не дата решения команды.

## Контекст и принятое решение

Ниже исходная запись Р15, сохранённая по смыслу и формулировкам; относительные ссылки заменены навигацией к источнику.

- **Контекст.** Исследование описывает 11 типовых кредитных сценариев и 2 сквозных модуля. Каталог ассистента — 16 направлений.
- **Решение.** Заявка в БД поддерживается для R01, R02, R03. Остальные направления помечены как неподдерживаемые и не подменяются обычным кредитом.
- **Почему.** Завершить оборотный путь целиком раньше, чем расширять каталог. Бизнес-БД содержит условия только R01–R03.
- **Последствия.** Другие продукты — план развития.

## Аргументы

Три продуктовых контракта позволяют завершить путь целиком; справочник не обещает транзакционную поддержку остальных направлений.

## Альтернативы и компромисс

Редакционный анализ при подготовке расширенной документации, не протокол исторического обсуждения команды: Расширить каталог раньше сквозного пути означало бы добавить продуктовые контракты, данные и тесты для каждого направления.
