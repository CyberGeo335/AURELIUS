# ADR-011: Ответственный сотрудник

Статус: действует в срезе `68b7b57c0e501e4575bc2a10eee20e6e42f529d4`. Дата принятия и автор ADR отдельно не установлены; развёрнуто 26.10.2026 из решения **Р11**. Это дата документирования, не дата решения команды.

## Контекст и принятое решение

Ниже исходная запись Р11, сохранённая по смыслу и формулировкам; относительные ссылки заменены навигацией к источнику.

- **Контекст.** Заявку не должны одновременно решать двое.
- **Решение.** Сотрудник берёт заявку в работу (`claim`). Скоринг, проверки и решение доступны только ответственному. Освободить заявку может только он сам. Общую очередь видят все сотрудники.
- **Почему.** Решение владельца продукта, в том числе для старых заявок без назначения.
- **Последствия.** Двойное назначение исключено блокировкой строки и проверкой версии. Назначения и освобождения пишутся в журнал.

## Аргументы

Назначение и блокировка предотвращают конкурирующие решения по одной заявке.

## Альтернативы и компромисс

Редакционный анализ при подготовке расширенной документации, не протокол исторического обсуждения команды: Общий доступ всех сотрудников к решению проще, но повышает риск конфликтующих действий.
