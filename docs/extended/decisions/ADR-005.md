# ADR-005: Кто что видит

Статус: действует в срезе `68b7b57c0e501e4575bc2a10eee20e6e42f529d4`. Дата принятия и автор ADR отдельно не установлены; развёрнуто 26.10.2026 из решения **Р5**. Это дата документирования, не дата решения команды.

## Контекст и принятое решение

Ниже исходная запись Р5, сохранённая по смыслу и формулировкам; относительные ссылки заменены навигацией к источнику.

- **Контекст.** Клиенту нужен понятный результат, а сотруднику — данные для решения. Внутренние оценки риска не должны становиться обещанием клиенту.
- **Решение владельца продукта.**
  - Клиент видит предложение банка (сумму, срок, ставку) и причину отказа, но не видит PD.
  - Сотрудник видит годовую PD, лимит PD и причины.
  - Категории риска и факторы модели не показываются никому.
- **Почему.** Решение владельца продукта. Шкалы категорий риска в скоринге нет (`risk_grade=UNRATED`): границы классов не выдумываются (scoring/main/README.md).
- **Последствия.** API не передаёт клиенту `assessment` и черновики предложений. Предложение клиент видит только после одобрения.

## Аргументы

Ролевые проекции дают клиенту действующий результат, а сотруднику — внутреннюю оценку для рассмотрения.

## Альтернативы и компромисс

Редакционный анализ при подготовке расширенной документации, не протокол исторического обсуждения команды: Показать клиенту всю внутреннюю оценку проще технически, но смешивает расчёт и опубликованный результат.
