# Архитектурные решения

Все 16 решений исходного [журнала Р1–Р16](../../02-decisions.md) развёрнуты с сохранением трассировки. Альтернативы помечены как редакционный анализ; даты принятия и авторы не придуманы. Основание актуальности — код версии из [PROGRESS](../PROGRESS.md).

| Источник | ADR | Решение |
|---|---|---|
| Р1 | [ADR-001](ADR-001.md) | Один кабинет поверх существующей БД, служебные данные — в отдельной схеме |
| Р2 | [ADR-002](ADR-002.md) | Скоринг читает финансовые данные только из БД банка |
| Р3 | [ADR-003](ADR-003.md) | Политика скоринга не меняется |
| Р4 | [ADR-004](ADR-004.md) | Скоринг не одобряет: решение принимает сотрудник |
| Р5 | [ADR-005](ADR-005.md) | Кто что видит |
| Р6 | [ADR-006](ADR-006.md) | Клиенту показываются только причины сотрудника |
| Р7 | [ADR-007](ADR-007.md) | Ассистент только предлагает, клиент подтверждает |
| Р8 | [ADR-008](ADR-008.md) | Неизвестное не заполняется догадками |
| Р9 | [ADR-009](ADR-009.md) | Демо-учётки и сессии |
| Р10 | [ADR-010](ADR-010.md) | Предложение действительно только для данных, на которых рассчитано |
| Р11 | [ADR-011](ADR-011.md) | Ответственный сотрудник |
| Р12 | [ADR-012](ADR-012.md) | Проверка сотрудника не исправляет исходные данные |
| Р13 | [ADR-013](ADR-013.md) | Документы хранятся в БД без извлечения данных |
| Р14 | [ADR-014](ADR-014.md) | Сценарий заканчивается принятием предложения |
| Р15 | [ADR-015](ADR-015.md) | Три продукта в заявке, 16 направлений в подборе |
| Р16 | [ADR-016](ADR-016.md) | Воспроизводимый запуск |
