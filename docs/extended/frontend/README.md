# Интерфейс работающего кабинета

Источник — [personalCab/web/src](../../../personalCab/web/src/), версия из [PROGRESS](../PROGRESS.md). Это документация React/TypeScript кабинета в HTTP-режиме, а не прежнего plain HTML фронта.

| Документ | Для чего |
|---|---|
| [DESIGN](DESIGN.md) | структура экранов, компоненты, токены и состояния |
| [FRONTEND-REQUIREMENTS](FRONTEND-REQUIREMENTS.md) | проверяемые критерии поведения по ролям |
| [references-v2](references-v2/README.md) | происхождение исторических решений и недоступные локальные материалы |

Пользовательские маршруты: клиент — главная/заявки/продукты/документы/компания; сотрудник — очередь/мои разборы/карточка рассмотрения/клиенты/политики/журнал. Источник — [App.tsx](../../../personalCab/web/src/app/App.tsx). `/` — вход; роль проверяется при открытии layout, чужая роль перенаправляется в свой кабинет. URL не даёт серверных прав: API отдельно проверяет сессию и владение.

Визуальная сверка работающего браузера в рамках документационной подготовки не выполнялась. Состояния и CSS ниже установлены по исходникам; это не протокол usability-теста. Проверки интерфейса и опубликованные прогоны — [08](../../08-testing.md).
