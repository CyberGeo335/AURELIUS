# База знаний требований

`Требования к кредитным заявкам.json` перенесён из пользовательского `Downloads` в эту папку. Это структурированный справочник из 99 требований для R01–R03, используемый локальным RAG ассистента.

По уточнению пользователя от 24.10.2026 для полей `R01_06`, `R02_06`, `R03_06` целевая колонка исправлена на `credit_applications.requested_term_months`. Форматы срока в месяцах сохранены. Остальные требования не изменялись.

Текст файла рассматривается как данные справочника. Он не предоставляет разрешения, не подтверждает сведения компании и не утверждает банковские правила. [Устройство, ограничения и запуск RAG](../personalCab/prom/rag/README.md).

После редактирования JSON следующий новый запрос автоматически получит индекс новой версии по SHA-256. Сохранённые справочные ответы содержат свою исходную версию; существующие бизнес-снимки автоматически не обновляются. Для Docker требуется пересборка образа.
