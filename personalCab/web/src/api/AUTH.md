# Вход: граница фронтенда и будущего сервера

Форма `pages/auth/Login.tsx` получает функции входа из SessionContext, не читает реестр пользователей напрямую. `AuthApi` внедряется в `Providers`:

```tsx
<Providers authApi={authAdapter}>
  <App />
</Providers>
```

Контракт:

- `signIn(SignInInput): Promise<AuthSession>`: роль запрашиваемого кабинета, имя, фамилия, логин и пароль. Ошибка — отклонённый Promise с понятным пользователю сообщением.
- `restore(): Promise<AuthSession | null>`: восстановить действующую сессию либо вернуть null. До ответа защищённый экран не открывается.
- `signOut(): Promise<void>`: завершить вход. После успеха UI очищает профиль и возвращается к форме.
- Необязательное `demoAccounts`: только публичные синтетические доступы. Серверный адаптер не задаёт это поле, поэтому кнопки и пароль демо не появляются.

`AuthSession` содержит публичный userId, роль, профиль компании, имя, фамилию и логин. Текущий кредитный mock поддерживает профили karpov/zerno; расширение списка компаний относится к подключению CreditApi. Пароль не входит в Session и не записывается в sessionStorage, localStorage или журнал.

`MockAuthApi` сопоставляет роль/логин/пароль с тремя публичными фикстурами. Имя и фамилия из формы используются только для демонстрационного отображения профиля; право на компанию и роль определяются фикстурой логина. Это не серверная граница доступа: содержимое хранилища и код браузера изменяемы пользователем.

При подключении БД адаптер должен получать канонические имя/фамилию, роль и разрешённую компанию от доверенного сервера; ввод пользователя не даёт банковских прав. БД и проверка пароля находятся на сервере. Для реальной сессии потребуется согласованный серверный механизм и проверка доступа на каждом кредитном запросе. Новые серверные URL, таблицы и cookie в этой задаче не создавались.

Существующий Python-сервер чата сохраняет собственную серверную личность и cookie. Новый вход не подменяет эту личность и не выдаёт согласия БКИ. Синхронизация серверного профиля чата и будущей кредитной сессии остаётся отдельной интеграцией.
