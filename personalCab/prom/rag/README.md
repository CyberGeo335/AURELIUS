# Справочник требований RAG

Проверено по коду коммита `6a9a4c1` (ветка `chore/cleanup-legacy`).

Справочные вопросы ассистента обслуживаются локальным поиском по `knowledge/Требования к кредитным заявкам.json`. Источник содержит 99 требований к продуктам R01–R03. Поиск учитывает продукт и тип заёмщика; ссылки возвращаются на конкретные требования.

Индекс строится в памяти: TF-IDF слов и символьных n-грамм, FAISS `IndexFlatIP`. Ответ собирается из найденных требований без генерации LLM. Текст справочника не изменяет сведения заявки и не подтверждает согласия.

В текущем кабинете RAG подключён через `ReferenceKnowledge` и Agent V2. Установка зависимостей и запуск — через корневые `requirements.txt` и Dockerfile. Отдельный сервер для RAG не нужен.
